🚀 Backend API Server

Welcome to the Backend API. This application is running with Vercel Speed Insights enabled.

ℹ️ Note: This is a RESTful API backend. Speed Insights is primarily designed for frontend applications, but has been configured here for demonstration purposes. The API endpoints below return JSON responses.

📡 Available API Endpoints

GET /

Root endpoint - Returns welcome message

GET /api/listing/check

Health check endpoint - Fetches external API data

POST /api/listing/register

User registration endpoint

Body: { username, password, address, mobile, email, usertype }

POST /api/listing/login

User login endpoint

Body: { email, password }

POST /api/listing/addmenu

Add menu item endpoint

Body: { dishname, price, dishimg, dishtype }

GET /api/listing/fetchmenu

Fetch all menu items

POST /api/listing/deletemenu

Delete menu item endpoint

Body: { dishname }

📊 Speed Insights

🔧 Technology Stack

  • Framework: Express.js
  • Database: MongoDB (Mongoose)
  • Deployment: Vercel
  • Monitoring: Vercel Speed Insights
